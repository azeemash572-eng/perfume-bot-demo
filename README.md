# MS Department Store — demo shop assistant

A **sample** WhatsApp-style shop assistant for **MS Department Store, Qurum, Muscat**. Built as a demo that shop owners can open on a phone.

**Demo by ASTRA AI.** Product prices and stock are placeholder data. Store hours, the Qurum address and the call-store number are for MS Department Store.

## Try it

https://azeemash572-eng.github.io/perfume-bot-demo/

Or open `index.html` in a browser. No login and no API keys — it works offline.

## What’s inside

One self-contained `index.html`. Rule-based replies in English and Arabic, with RTL bubbles for Arabic. Sample catalog of 30 items: perfumes, watches, luggage, cookware and small kitchen appliances, priced in OMR. The WhatsApp owner button is a demo placeholder. The store phone (9679 2580) is for calling only.
