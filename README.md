# Oud & Time Demo Store

A **sample** WhatsApp-style shop assistant for a perfume and watch shop in Muscat, Oman. Built as a demo that shop owners can open on a phone.

**Demo by ASTRA AI.** All prices, stock, hours and the location are placeholder data.

## Try it

Open `index.html` in a browser, or the GitHub Pages URL after deploy. No login and no API keys — it works offline.

## Example questions

**English**
- Hello
- How much is Rasasi Hawas?
- Is Dior Sauvage in stock?
- Gift under 20 rial
- Show me oud scents
- For her
- Shop hours / Where are you?
- Talk to owner

**Arabic**
- السلام عليكم
- كم سعر هوس؟
- هدية بـ 20 ريال
- عطور العود
- عطور رجالية
- ساعات العمل
- تحدث مع المالك

**Roman Urdu**
- Salam
- Hawas ka price kya hai
- Gift 20 rial ke under
- Timing kya hai
- Malik se baat

## What’s inside

One self-contained `index.html` (HTML/CSS/JS). Rule-based replies in English and Arabic, with RTL bubbles for Arabic. Sample catalog: 15 perfumes and 5 watches, priced in OMR.
